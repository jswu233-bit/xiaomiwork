# 2. Performance Bonus Rules

# 2. 绩效奖金规则

## 2.1 DRM & ARM

## 2.1 DRM与ARM

* **Quarterly assessment, monthly payment.** The performance bonus for the current quarter will be evenly distributed on a monthly basis in the following quarter;

* **按季度考核，按月发放。** 当季度绩效奖金将在次季度按月平均发放；

* **Quarterly Performance Bonus** = <u>Individual Quarterly Target Performance Bonus Base x Individual Performance Bonus Coefficient for the Current Quarter</u>

* **季度绩效奖金** = <u>个人季度目标绩效奖金基数 × 当季度个人绩效奖金系数</u>

| **Individual performance achievement score (Z)**<br />**个人绩效得分（Z）** | **Individual Performance Bonus Coefficient**<br />**个人绩效奖金系数**                |

| Z ≥ 120                                                             | **<span style="color: rgb(216,57,49); background-color: inherit">1.3</span>** |
| 90 ≤ Z < 120                                                        | Z/100                                                                         |
| 80 ≤ Z < 90                                                         | 0.8                                                                           |
| Z < 80                                                              | 0                                                                             |
